# Roadmap — FNG Companion

Sin fechas arbitrarias. Las versiones se publicarán como **tags/releases**, no en el nombre del repo.

| Versión/etapa | Alcance | Condición de salida |
| --- | --- | --- |
| **Pre-0.1** | MV3, panel lateral, Meta + Google, registro local, docs y CI | Compila + QA de Chrome real |
| **v0.1.0** | Sesiones estables y recordatorio pasivo local | Tiempo/foco confiables, pausa, cero navegación fuera de plataformas |
| **v0.2.0** | Mapping cuenta externa → cliente + vínculo seguro FNG | IDs resueltos manualmente, ingesta autorizada/idempotente |
| **v0.3.0** | Bandeja de sesiones no documentadas | Relación entre sesión y revisión con silencio al registrar |
| **v0.4.0** | Cobertura de revisión y recordatorios configurables | Solo cuentas programadas; snooze, cooldown, ventanas |
| **v0.5.0** | Push a PWA móvil (en FNG) | Backend scheduler y Web Push probado en dispositivo |
| **Futuro** | Mayor contexto de acciones autorizado | Cualquier evento enriquecido se etiqueta según su evidencia |

No planificar scraping de campañas como requisito del MVP. El valor principal es eliminar el olvido de sesiones y revisiones, sin utilizar Marketing API.
